# Hackathon Registration - State of Ohio

Touch-first check-in SPA for event operations.

## Architecture

- Frontend: static SPA (`frontend/`) with Fluent-style, large touch targets
- API: Azure Functions (`api/`) for attendee lookup, check-in, and dashboard
- Datastore: Azure Table Storage (production) or local JSON fallback (development)
- Initial data: screenshot-derived records in `sample-data/initial-registrations.json`

## Core Fields

- `status`
- `name`
- `title`
- `agency`
- `trackSelected`

Additional operational fields are generated by the API: `registrationId`, `lastName`, `lastInitial`, `checkedInAtUtc`.

## Features Implemented (MVP)

- Dynamic initial buttons showing only letters that exist in registration data
- Attendee list by selected initial
- Detail pane with one-tap check-in
- Idempotent check-in updates with timestamp
- Admin import for CSV/Excel registration exports
- Checked-in attendee CSV export
- Current Registration view with:
  - Total Registrants
  - Total Checked-In
  - Track buttons for No Code, Low Code, Pro Code
  - Accordion grouping by agency for selected track

## Local Development

### 1) Start API

```bash
cd 10-event-checkin-spa/api
npm install
copy local.settings.example.json local.settings.json
npm start
```

Notes:
- By default, `USE_TABLE_STORAGE=false`, so data is stored in `api/data/registrations.local.json`.
- To use Azure Table Storage, set `USE_TABLE_STORAGE=true` and provide `AZURE_TABLE_CONNECTION_STRING`.

### 2) Start Frontend

Any static server works. Example with Python:

```bash
cd 10-event-checkin-spa/frontend
python -m http.server 5173
```

Then open:
- `http://localhost:5173`

If your API is not on `/api`, set `window.__API_BASE__` before loading `assets/app.js`.

### 3) Import Full Registration File

- Open `Current Registration` tab.
- Use `Import Registrations (CSV or Excel)`.
- Choose a `.csv`, `.xlsx`, or `.xls` file.
- Click `Import File`.

Accepted columns (case-insensitive fallback supported):
- `Status`
- `Name`
- `Title`
- `Agency`
- `TrackSelected` (or `Track`)
- Optional: `RegistrationId`, `CheckedInAtUtc`

### 4) Export Checked-In Attendees

- Open `Current Registration` tab.
- Click `Download Checked-In CSV`.
- The app downloads a CSV of attendees with `Status=Checked-In`.

## API Endpoints

- `GET /api/health`
- `GET /api/initials`
- `GET /api/attendees?initial={A-Z}`
- `GET /api/attendees/{registrationId}`
- `POST /api/attendees/{registrationId}/checkin`
- `GET /api/dashboard`
- `GET /api/tracks/{track}/agencies`
- `POST /api/admin/import`

## Azure Deployment Direction

This module is designed for:
- Azure Static Web Apps (frontend)
- Azure Functions (api)
- Azure Storage Account Table service (data)

Production uses a Function App managed identity with `Storage Table Data Contributor` on the storage account, which avoids shared-key authentication.
